# Tag Group Organizer

[English](README.md) | 简体中文

Tag Group Organizer lets you arrange existing Obsidian tags into visual groups and blocks without changing their original tag structure.

![Tag Group Organizer](https://tupian.li/images/2026/09/03/6a98e6312a32e.png)

---

### 简介

Tag Group Organizer 是一款用于整理 Obsidian 标签的本地插件。它会读取仓库中已有的标签，并允许你按照自己的工作方式将标签放入不同分组和块中。

普通的分组、移动和排序操作只会改变插件自己的组织数据，不会修改笔记中的标签。

### 主要功能

- 将已有标签整理到自定义分组中。
- 在同一分组内使用多个标签块进一步划分标签。
- 通过拖拽移动或复制标签。
- 锁定分组，避免误操作。
- 按名称或使用频次排序标签和分组。
- 搜索当前仓库中的标签。
- 单击标签，在 Obsidian 中搜索包含该标签的笔记。
- 从右键菜单管理标签所属分组。
- 重命名分组或删除分组。
- 重命名标签，并同步修改支持的 Markdown 正文标签和 YAML 标签列表。
- 根据 Obsidian 的界面语言自动显示中文或英文。

### 安装

#### 从 Obsidian 社区插件安装

1. 在 Obsidian 中打开 **设置 → 第三方插件**。
2. 点击 **浏览**，搜索 **Tag Group Organizer**。
3. 点击 **安装**。
4. 安装完成后，点击 **启用**。

#### 手动安装

你也可以从 [GitHub 最新版本](../../releases/latest) 手动安装：

1. 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在仓库的 `.obsidian/plugins/` 目录下创建名为 `tag-group-organizer` 的文件夹。
3. 将下载的三个文件放入该文件夹。
4. 重新加载 Obsidian，然后前往 **设置 → 第三方插件** 启用 **Tag Group Organizer**。

需要 Obsidian `1.8.7` 或更高版本。

### 快速开始

1. 选择左侧功能区中的标签图标，或运行命令 **打开标签管理器**。
2. 选择工具栏中的加号按钮创建分组。
3. 将标签拖到分组标题，标签会加入该分组的第一个块。
4. 将标签拖到分组底部的放置区域，可以创建新块。
5. 选择分组标题可展开或收起分组。
6. 选择锁图标可锁定或解锁分组。

### 拖拽规则

- 在同一分组的不同块之间拖拽：移动标签。
- 从一个分组拖到另一个分组：复制标签，原分组中的标签会保留。
- 将标签拖到分组标题：加入目标分组的第一个块。
- 将标签拖到分组底部：创建一个包含该标签的新块。
- 已锁定的分组不接受标签拖入，也不能修改分组内容。

将标签拖到 Obsidian 编辑器时，插件仍会插入标准的 `#标签` 格式。

### 右键菜单

右键单击标签可以：

- 从当前分组移除标签。
- 重命名标签。
- 查看标签所属分组，并添加到或移出其他未锁定分组。

右键单击分组标题可以：

- 重命名分组。
- 删除分组。

删除分组只会删除插件中的组织信息，不会删除仓库中的标签或笔记。

### 排序与频次

工具栏支持按名称和使用频次排序。使用频次表示仓库中包含该标签的笔记数量；同一篇笔记中的相同标签只计算一次。

### 标签重命名注意事项

标签重命名会修改仓库文件。使用前建议备份仓库或启用版本控制。

当前重命名支持：

- Markdown 正文中的标签。
- YAML Frontmatter 中采用列表形式保存的 `tags`。

标签名称不能包含空格。

### 数据与隐私

- 插件数据保存在本地插件目录的 `data.json` 中。
- 插件不会发送遥测数据。
- 插件不会将仓库内容发送到外部服务。
